# 🚀 AutoPartsPro Setup Guide\n\n## ✅ What's Ready\n\nYour repository is now fully organized with:\n\n- ✅ **Frontend** (Next.js 14) — Product catalog, cart, UI components\n- ✅ **Backend** (FastAPI) — REST API with authentication, products, orders\n- ✅ **Database** (PostgreSQL) — Schema with models for products, users, orders\n- ✅ **API Integration** — TypeScript client ready to connect frontend ↔ backend\n- ✅ **Documentation** — Complete guides for development and deployment\n\n---\n\n## 🎯 Quick Start (5 minutes)\n\n### 1. Start the Backend\n\n```bash\ncd backend\ndocker-compose up -d\n```\n\nThis starts:\n- PostgreSQL database on `localhost:5432`\n- FastAPI server on `localhost:8000`\n- Interactive API docs at `http://localhost:8000/docs`\n\n### 2. Seed Sample Data (Optional)\n\n```bash\ncd backend\npython seed.py\n```\n\nThis loads:\n- 6 sample products (spark plugs, oil, filters, etc.)\n- Demo user (email: `demo@autoparts.ke`, password: `password123`)\n- 6 product categories\n\n### 3. Start the Frontend\n\n```bash\n# In a new terminal, from root directory\nnpm install\nnpm run dev\n```\n\nOpen `http://localhost:3000` in your browser.\n\n---\n\n## 📚 API Documentation\n\n**Interactive Swagger UI:** http://localhost:8000/docs\n\nKey endpoints ready to use:\n\n```typescript\n// Import the API client\nimport { api } from '@/lib/api'\n\n// Get all products\nconst products = await api.products.list()\n\n// Get categories\nconst categories = await api.categories.list()\n\n// Login\nconst user = await api.auth.login('demo@autoparts.ke', 'password123')\n\n// Add to cart\nawait api.cart.addItem('prod-1', 1)\n\n// Get cart\nconst cart = await api.cart.get()\n```\n\nSee `src/lib/api.ts` for complete API client.\n\n---\n\n## 📁 Project Structure\n\n```\nauto-parts/\n├── src/                    # Create a feature branch:\n   ```bash\n   git checkout -b feature/your-feature\n   ```\n\n2. Make changes and commit:\n   ```bash\n   git commit -am \"Add feature\"\n   ```\n\n3. Push and create a Pull Request:\n   ```bash\n   git push origin feature/your-feature\n   ```\n\n### Frontend Changes\n- Edit components in `src/components/`\n- Add pages in `src/app/`\n- Update types in `src/types/`\n- Use `api` client instead of mock data\n\n### Backend Changes\n- Add models in `backend/app/models/`\n- Add endpoints in `backend/app/routes/`\n- Add validation schemas in `backend/app/schemas/`\n- Create migrations: `alembic revision --autogenerate -m \"description\"`\n\n---\n\n## 🧪 Testing the Integration\n\n### 1.
